## 2024-07-20 - Try/Except in CC3D spatial loops is an anti-pattern
**Learning:** In CompuCell3D, out-of-bounds array lookups on fields (like `self.cell_field`) throw C++ exceptions via SWIG. Wrapping nested spatial loops in `try...except` and catching these exceptions (or blindly using manual if checks against hardcoded bounds) is computationally expensive, especially since these checks are evaluated per cell, per step.
**Action:** Instead of using `if 0 <= nx < 500` or relying on `try...except` inside tightly nested loops to catch out-of-bounds access, use `max()` and `min()` with dynamic boundaries (`self.dim.x`, `self.dim.y`) when computing `range()` parameters before the loop. This ensures the loop inherently never goes out of bounds, avoiding both the explicit `if` check inside the loop and the expensive SWIG C++ exception throwing overhead.
